RectorJs

Modern extensible block editor. Vanilla JavaScript, zero dependencies, clean JSON output.

Try Demo Documentation

Everything you need

Block Architecture

Modular content blocks — paragraphs, headings, lists, images, video, tables. Each block is independent.

21+ Plugins

Image, gallery, embed, code, table, checklist, quote, toggle, columns, poll. Build your own with a simple API.

Inline Tools

Bold, italic, links, code, font size, text color, alignment — floating toolbar and keyboard shortcuts.

Drag & Drop

Reorder blocks with smooth FLIP animations. Drag handle on every block for intuitive management.

Undo / Redo

Snapshot-based history with debounce. Ctrl+Z / Ctrl+Shift+Z across all operations.

Clean JSON

Structured block data. Each block stores type + data. Serialize, store, and render on any platform.

i18n

Built-in English and Russian. Add any language with a translation dictionary.

Themes

CSS custom properties for full theming. Dark and light modes at runtime. Build your own theme.

Zero Dependencies

No React, no Vue, no frameworks. Pure vanilla JavaScript, works everywhere.

Up and running in minutes


      

        
app.js

        
import { createEditor, Paragraph, Heading } from 'rectorjs'

const editor = createEditor({
  holder: document.getElementById('editor'),
  plugins: [
    new Paragraph(),
    new Heading(),
  ],
  locale: 'en',
  theme: 'dark',
  onChange(data) {
    console.log(data)
  },
})

// Save content as JSON
const data = await editor.save()
