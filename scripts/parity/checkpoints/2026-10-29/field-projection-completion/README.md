# Rich-field completion and Image derived alternative text

This slice adds optional synchronous `BlockInstance.afterProjection(field)` under the existing BlockReconciler projection owner. The captured exact rich-field descriptor grants completion only after real projection, including native normalization that makes no canonical commit. The callback updates owned auxiliary presentation before acceptance. It cannot write author content, model/history, focus or tasks; failures use existing operation recovery and field-local containment. No second lifecycle registry, event bridge, polling or canonical no-op action is introduced. Image computes its alternative text from completed caption content and checks its exact image/caption/container relationship before an auxiliary write.

The frozen Image ten-case oracle first exposed five actual alternative-text failures. Independent third-party contract controls then established callback capture/receiver, precommit timing, normalized native no-op, mode cancellation, field-local failure/recovery, no query replay, synchronous errors/thenables and exact ownership. Additional RED controls exposed same-HTML descendant replacement, direct author writes, damaged sibling fields and an adopted Image auxiliary node. All are retained in the archive.

The exact final isolated bytes passed 1967 unit tests, seven generated declaration consumers, both checked-JavaScript projects, package installation/external browser contracts, 100 projection cases, 63 presentation cases, 28 mode cases and the complete 36-case native-library plus 14-case native-presentation pages. These are scoped results and overlap; they do not replace the full integrated library run.

`review-manifest.json` is the original immutable review manifest. `archive-index.json` records every original log/manifest/patch hash. `isolated-proof.tar.gz` is a lossless archive verified against that index; `integration.json` maps the admitted source to the main branch and identifies the later two-line Russian documentation correction. Historical package layout, missing-browser and invalid-oracle attempts remain accurately labeled failed. The archive's original README mentions the integrated run while it was in progress; that run subsequently stopped on the two untranslated prose terms, after its unit, type and package gates passed. Remaining browser/heap gates run separately after that documentation-only fix.

This slice repairs the supported Image caption-derived attribute and extends the public optional hook. Full Image/Gallery roundtrip acceptance and detailed block actions remain independent obligations.
