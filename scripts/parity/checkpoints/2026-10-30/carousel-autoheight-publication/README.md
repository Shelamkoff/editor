# Published Carousel dependency and clean installation

The Rector dependency is pinned to
`git+https://github.com/Shelamkoff/carousel.git#f7f6485886a1d77f9213d9079eb70000efeff499`.
This is a narrow release backport, preserving the installed npm 1.0.0 runtime
except for the observed-layout repair. It does not adopt unrelated changes from
the current upstream master. The independent source RED/GREEN and the earlier
failed packaging attempts are in the adjacent `carousel-autoheight-dependency`
checkpoint; those historical outcomes remain unchanged.

The first upstream source commit is `03cfb7b6e2a716e71435646fe9041e42cbd57020`,
tree `0f86a8dd69746748fb67409f4c3cafa2443258d4`. The next commit, the pinned
`f7f64858`, contains the 47 distribution files generated by the existing package
builder, tree `d71d783ab0a030c3c538aea3bee5b0ee944bc01a`. Their bytes match the
reviewed build. Including this distribution makes Git installation work with
lifecycle scripts disabled, as required by Rector's existing CI. There is no
consumer-side patch or generated runtime shim.

A new consumer and empty npm cache executed both `npm install --ignore-scripts`
and `npm ci --ignore-scripts` against the actual published SHA. Both exited zero;
the public ESM entry and stylesheet loaded, and all 47 installed distribution
files matched the frozen build. The original commands, timestamps, logs,
package/lock files, hashes and verification script are retained here. A separate
check confirmed the same 47 bytes in the integrated Rector installation.

Both Git tree publications were checked against the full local tree SHA before
updating the isolated upstream branch. The publication JSON files retain the
local-to-published commit mapping. No npm version was published and upstream
master was not changed by the release-backport publication.

The same source fix was also prepared against current upstream master and
published as `ebbc9758e3d4fdef415335e692b14538cecabb72` in
[draft pull request #1](https://github.com/Shelamkoff/carousel/pull/1).
That separate patch changes only TrackRenderer and its unit/browser controls.
Its complete local verification, including the original Chromium CDN TLS
failure and the exact cached-response runtime control, is retained in
`../carousel-upstream-master/`. Native CDN success is left to the upstream CI;
the cached-response run is not relabelled as a successful network smoke test.
