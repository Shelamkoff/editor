# Рендереры блоков

Для каждого встроенного блока существует фабричная функция. Импортируйте его из `@shelamkoff/rector/renderer/renderers/<path>`, полный готовый набор — из `@shelamkoff/rector/renderer/renderers`, ленивые фабричные функции — из `@shelamkoff/rector/renderer/renderers/async`.

Фабричная функция создаёт DOM, объявляет фактически необходимые URL стилей (массив может быть пустым), при необходимости преобразует поля с виджетами и предоставляет освобождение ресурсов владельцу `EditorRenderer`. Контракт расширения описан в последовательном руководстве VitePress.
