## Расширение покрытия

- Каждый из **21 целевого типа** проверен тремя способами: whole conversion через тюн, частичный фрагмент через тюн и через inline toolbar — **63 сценария**. Для обычного текста доступны все типы. Проверены неизменность невыделенного tail, prefix/suffix, фокус и один Undo/Redo. Для Paragraph исходным типом служит Heading.
- Дополнительно все **21 цели × два меню × два направления = 84 cross-block сценария** проверяют число целей, внешний prefix, невыделенный третий пункт List с прежним ID/стилем, остальные блоки, отсутствие старого native range/тулбара и направленный диапазон на одном Undo/Redo. Два случая Image с inline-виджетами сохраняют невыделенный widget и восстанавливают выбранный на Undo; два случая стороннего caption target проверяют сам контракт, без списка имён плагинов в ядре.
- Forward/backward cross-block conversion через тюн проверяет преобразованные куски, внешний остаток, IDs и восстановление исходного направления/offsets на Undo. Добавлены смешанные Heading/Paragraph и цели Gallery/Carousel.
- Move проверяется после анимации, на промежуточных кадрах, с длительностями 0/500 ms, повторным Up/Down, readOnly и историей. Native drag дополнительно проверяет расположение кнопок после drag/Undo/Redo вместе с прежними проверками DOM identity и каретки.
- Image проверяется с отдельной панелью, изменением фактической ширины, переключателями, блокировкой ширины Expanded, escape/resize, узким viewport и историей. Browser surface contract переведён на отдельную кнопку.
- Повторён полный набор ядра и 21 плагина: native input, cross-selection, conversion, структурные операции, clipboard, IME protocol, plugin fields/controls/ranges/media/design и lifecycle.
- На действующем и production-демо RU/EN нативно проверены межблочная замена Paragraph и первых двух пунктов List одним Image, отсутствие старого выделения/тулбара, сохранение третьего пункта и Undo/Redo. Также проверены Move down с геометрией кнопок, частичная конверсия заголовка через тюн, Undo/Redo и неизменность других блоков. Проверки локализованных подсказок, меню Heading/conversion в обеих темах, поиска и Align сохранены.

## Архитектура и границы вывода

У контроллеров остаётся UI ownership. Они сохраняют bookmark и выбирают цель, а data slicing, canonical assembly, inline filtering и атомарная история остаются в DocumentRuntime. Тюн не получил собственного DOM splitter или второго registry. `selectionMode` — data capability, ядро не перечисляет типы. Значение по умолчанию `single`; автор стороннего текстового плагина явно выбирает `per-block`. Прежнее сохранение отдельных текстовых фрагментов Code в v2 остаётся; его inline-loss guard не заменён созданием пустого блока. Whole и partial/cross пути используют один helper импорта/defaults. Неподдерживаемое сохранение связанных inline references продолжает отклоняться до замены; проверка Code/unknown-inline входит в общий прогон.

Согласованное владельцем сохранение всех авторских полей при whole conversion в текст остаётся в силе, включая Quote caption, Person role/bio и Poll options. Выбор нетекстового default-блока — явная пользовательская замена, для которой можно отменой вернуть исходный текст; он не подменяет неподдерживаемую вставку Clipboard.

Подтверждена перечисленная матрица на Chrome. Протокольные IME-сценарии не означают проверку всех системных IME; реальные загрузчики и server adapters требуют окружения приложения. Абсолютное отсутствие любых ошибок и полная визуальная идентичность во всех браузерах из этих gates не следуют. Демо для проверки владельцем: `http://127.0.0.1:5173/ru/#demo`.
