# Блочный плагин Code

Блок кода с выбором языка и необязательной подсветкой синтаксиса.

## Установка и регистрация

```bash
npm install @shelamkoff/rector
```

```js
import { createEditor } from '@shelamkoff/rector'
import { Code } from '@shelamkoff/rector/plugins/code'
import '@shelamkoff/rector/styles/editor.css'

const editor = createEditor({
  holder: document.querySelector('#editor'),
  plugins: [new Code()],
})
```

Тип блока — `code`. Класс также экспортируется общей точкой входа `@shelamkoff/rector/plugins` и может загружаться по типу документа через `@shelamkoff/rector/plugins/async`.

## Данные

```json
{ "code": "const value = 1", "language": "javascript" }
```

### Поля данных

| Поле | Обязательно | Назначение и ограничения |
| --- | --- | --- |
| `code` | да | Непустой исходный текст. Он никогда не выполняется как HTML. |
| `language` | нет | Идентификатор языка для подсветки. Новый блок сохраняет `auto`, пока пользователь не выберет другой язык. Неизвестная строка остаётся допустимыми данными; если модуль подсветки не распознает её, код отображается как обычный текст. |

Пустой блок кода допустим как черновик, но не проходит строгую проверку сохранённых данных.

## Конфигурация

Каждый встроенный блочный плагин принимает два параметра владения стилями: `injectStyles?: boolean` по умолчанию равен `true`; укажите `false`, если приложение само включает CSS этого плагина. `css?: string` добавляет URL таблицы стилей приложения после стандартной, а при отключённой стандартной инъекции служит URL замены.

`hljs?: object` передаёт совместимый экземпляр highlight.js. Без него встроенная подсветка загружается по требованию; если она недоступна, код остаётся обычным текстом.

Меню языка содержит встроенные идентификаторы, поддерживаемые поставляемой подсветкой. Документ может хранить и любую другую непустую строку языка. Она сохраняется и отображается, даже если отсутствует в меню; когда текущий модуль подсветки её не распознаёт, блок показывает экранированный исходный текст без подсветки. Кнопка копирования использует браузерный API буфера обмена `navigator.clipboard`. Если этот интерфейс недоступен или запись отклонена, документ и состояние кнопки не меняются.


## Возможности

Вставка `code`, `pre` и ограждённого блока кода; доступные с клавиатуры выбор и фильтрация языка; необязательная подсветка; копирование через API буфера обмена; преобразование блока.

## История, жизненный цикл и стили

Действия плагина входят в конвейер команд через предоставленный контекст `mutate()`, поэтому одно завершённое действие создаёт один шаг отмены и повтора. Редактор подсчитывает владельцев объявленных URL стилей. Удаление блока вызывает его метод освобождения ресурсов; `editor.destroy()` освобождает оставшиеся блоки и общие ресурсы.

Не удаляйте контейнер редактора до вызова `editor.destroy()`.

## Вывод документа

Используйте фабричную функцию из `@shelamkoff/rector/renderer/renderers/code`. Последовательное руководство VitePress описывает проверку данных, миграции, разработку расширений, диагностику, безопасность и стили.
