# Блочный плагин LinkPreview

Предварительный просмотр ссылки с семью шаблонами и необязательными метаданными приложения.

## Установка и регистрация

```bash
npm install @shelamkoff/rector
```

```js
import { createEditor } from '@shelamkoff/rector'
import { LinkPreview } from '@shelamkoff/rector/plugins/link-preview'
import '@shelamkoff/rector/styles/editor.css'

const editor = createEditor({
  holder: document.querySelector('#editor'),
  plugins: [new LinkPreview()],
})
```

Тип блока — `linkPreview`. Класс также экспортируется общей точкой входа `@shelamkoff/rector/plugins` и может загружаться по типу документа через `@shelamkoff/rector/plugins/async`.

## Данные

```json
{
  "url": "https://example.com",
  "title": "Пример",
  "description": "",
  "image": "",
  "favicon": "",
  "domain": "example.com",
  "template": "notion"
}
```

### Поля данных

| Поле | Обязательное | Назначение и ограничения |
| --- | --- | --- |
| `url` | да | Канонический внешний адрес HTTP или HTTPS. |
| `title`, `description`, `domain` | нет | Строки метаданных; пустые значения допустимы. |
| `image`, `favicon` | нет | Пустые строки или канонические адреса, разрешённые политикой медиафайлов. |
| `template` | нет | `horizontal`, `compact`, `large-top`, `minimal`, `twitter`, `notion` или `split`; редактор и рендерер по умолчанию используют `notion`. |

`template` принимает `horizontal`, `compact`, `large-top`, `minimal`, `twitter`, `notion` или `split`. Разрешены только ссылки HTTP и HTTPS.

## Конфигурация

Каждый встроенный блочный плагин принимает два параметра владения стилями: `injectStyles?: boolean` по умолчанию равен `true`; укажите `false`, если приложение само включает CSS этого плагина. `css?: string` добавляет URL таблицы стилей приложения после стандартной, а при отключённой стандартной инъекции служит URL замены.

`fetchMeta(url, { signal })` возвращает `title`, `description`, `image`, `favicon` и `domain` и должен учитывать переданный `AbortSignal`. Адреса изображения и значка проходят общую политику адресов медиафайлов. Без этого обработчика плагин не выполняет запрос метаданных: он сохраняет очищенный URL, определяет `domain`, а остальные поля остаются пустыми, пока их не передаст приложение или загруженный документ.

Если настроен `fetchMeta`, ввод нового адреса запускает одно отменяемое получение метаданных. После завершения обработчика плагин одновременно сохраняет адрес и нормализованные метаданные, поэтому один ввод адреса остаётся одним шагом отмены и повтора. При ошибке сохраняется очищенный адрес без необязательных метаданных. Новый адрес или удаление блока прерывает предыдущий запрос и не позволяет устаревшему ответу изменить документ.


## Возможности

Вставка URL; асинхронное получение метаданных; выбор шаблона; безопасное назначение URL; освобождение ресурсов. Пока блок доступен для редактирования, нажатие карточки не открывает адрес и не уводит пользователя из редактора. В режиме отображения редактора и в готовом документе карточка работает как обычная внешняя ссылка.

## История, жизненный цикл и стили

Действия плагина входят в конвейер команд через предоставленный контекст `mutate()`, поэтому одно завершённое действие создаёт один шаг отмены и повтора. Редактор подсчитывает владельцев объявленных URL стилей. Удаление блока вызывает его метод освобождения ресурсов; `editor.destroy()` освобождает оставшиеся блоки и общие ресурсы.

Не удаляйте контейнер редактора до вызова `editor.destroy()`.

## Вывод документа

Используйте фабричную функцию из `@shelamkoff/rector/renderer/renderers/link-preview`. Последовательное руководство VitePress описывает проверку данных, миграции, разработку расширений, диагностику, безопасность и стили.
