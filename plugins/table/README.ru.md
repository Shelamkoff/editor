# Блочный плагин Table

Редактируемая таблица с необязательной строкой заголовков.

## Установка и регистрация

```bash
npm install @shelamkoff/rector
```

```js
import { createEditor } from '@shelamkoff/rector'
import { Table } from '@shelamkoff/rector/plugins/table'
import '@shelamkoff/rector/styles/editor.css'

const editor = createEditor({
  holder: document.querySelector('#editor'),
  plugins: [new Table()],
})
```

Тип блока — `table`. Класс также экспортируется общей точкой входа `@shelamkoff/rector/plugins` и может загружаться по типу документа через `@shelamkoff/rector/plugins/async`.

## Данные

```json
{ "withHeadings": true, "content": [["Название", "Значение"], ["А", "1"]] }
```

### Поля данных

| Поле | Обязательно | Назначение и ограничения |
| --- | --- | --- |
| `content` | да | Непустой прямоугольный массив строк как минимум с одним столбцом. Каждая ячейка должна быть строкой. Новая таблица создаётся размером 3 на 3. |
| `withHeadings` | нет | Логическое значение, указывающее, является ли первая строка заголовочной; при отсутствии считается `false`. |

Ячейки содержат очищенный внутристрочный HTML. В каждой ячейке работают включённые внутристрочные инструменты и постоянные внутристрочные виджеты; данные виджетов сохраняются в карте `inline` блока так же, как в других форматируемых блоках.

## Конфигурация

Каждый встроенный блочный плагин принимает два параметра владения стилями: `injectStyles?: boolean` по умолчанию равен `true`; укажите `false`, если приложение само включает CSS этого плагина. `css?: string` добавляет URL таблицы стилей приложения после стандартной, а при отключённой стандартной инъекции служит URL замены.


## Возможности

Форматирование; добавление и удаление строк и столбцов; строка заголовков; вставка таблицы; преобразование блока.

## История, жизненный цикл и стили

Действия плагина входят в конвейер команд через предоставленный контекст `mutate()`, поэтому одно завершённое действие создаёт один шаг отмены и повтора. Редактор подсчитывает владельцев объявленных URL стилей. Удаление блока вызывает его метод освобождения ресурсов; `editor.destroy()` освобождает оставшиеся блоки и общие ресурсы.

Не удаляйте контейнер редактора до вызова `editor.destroy()`.

## Вывод документа

Используйте фабричную функцию из `@shelamkoff/rector/renderer/renderers/table`. Последовательное руководство VitePress описывает проверку данных, миграции, разработку расширений, диагностику, безопасность и стили.
