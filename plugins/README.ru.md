## Загрузка типов документа

```js
import { createBlockPluginsAsync } from '@shelamkoff/rector/plugins/async'
const plugins = await createBlockPluginsAsync(documentData, { image: { uploadFile }, gallery: { uploadFile } })
```

Загрузчик удаляет дубликаты, сохраняет стандартный порядок и отклоняет неизвестные типы. Контракт плагина, история, стили, локализация, жизненный цикл и безопасность описаны в последовательном руководстве VitePress.
