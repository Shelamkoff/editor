# Блочный плагин Toggle

Сворачиваемый блок с заголовком, форматируемым содержимым и сохраняемым состоянием.

## Установка и регистрация

```bash
npm install @shelamkoff/rector
```

```js
import { createEditor } from '@shelamkoff/rector'
import { createTogglePlugin } from '@shelamkoff/rector/plugins/toggle'

const editor = createEditor({
  holder: document.querySelector('#editor'),
  plugins: [createTogglePlugin()],
})
```

Тип блока — `toggle`. Фабричная функция также экспортируется общей точкой входа `@shelamkoff/rector/plugins` и может загружаться по типу документа через `@shelamkoff/rector/plugins/async`.

## Данные

```json
{ "title": "Подробности", "content": "Скрытый текст", "open": false }
```

### Поля данных

| Поле | Обязательно | Назначение и ограничения |
| --- | --- | --- |
| `title` | да | Строка с очищенным внутристрочным HTML; может быть пустой. |
| `content` | да | Строка с очищенным внутристрочным HTML; может быть пустой. |
| `open` | нет | Логическое значение исходного состояния раскрытия; при отсутствии считается `false`. |

Хотя бы одно из полей `title` и `content` должно быть непустым. Сохранённое значение `open` позволяет рендереру воспроизвести выбранное исходное состояние.

## Конфигурация

Каждый встроенный блочный плагин принимает два параметра владения стилями: `injectStyles?: boolean` по умолчанию равен `true`; укажите `false`, если приложение само включает CSS этого плагина. `css?: string` добавляет URL таблицы стилей приложения после стандартной, а при отключённой стандартной инъекции служит URL замены.


## Возможности

Форматирование; редактирование заголовка и содержимого; объединение; сохраняемое раскрытие; клавиатурная доступность.

## История, жизненный цикл и стили

Нативный ввод в зарегистрированных редактируемых полях и изменения данных через `context.updateData()` или `context.commitDomMutation()` входят в канонический конвейер транзакций редактора. Одно завершённое изменение документа создаёт один шаг отмены и повтора; переключение представления не создаёт историю. Редактор подсчитывает владельцев объявленных URL стилей. Удаление блока вызывает его метод освобождения ресурсов; `editor.destroy()` освобождает оставшиеся блоки и общие ресурсы.

Не удаляйте контейнер редактора до вызова `editor.destroy()`.

## Вывод документа

Используйте фабричную функцию из `@shelamkoff/rector/renderer/renderers/toggle`. Последовательное руководство VitePress описывает проверку данных, миграции, разработку расширений, диагностику, безопасность и стили.
