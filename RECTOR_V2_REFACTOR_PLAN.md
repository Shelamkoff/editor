# Rector v2 — первоначальная спецификация заменена

Действующий план: [спецификация исправлений без legacy-совместимости](RECTOR_V2_REMEDIATION_SPEC.md).

[Первоначальный текст в истории Git](https://github.com/Shelamkoff/editor/blob/bf19263b1135745ee4e6a6479597cb2c4e5c0eb4/RECTOR_V2_REFACTOR_PLAN.md) сохранён для анализа решений, но не является действующей инструкцией для coding agent. Его положения о миграциях, поддержке старых данных, preserved-document mode и переходных API отменены уточнёнными требованиями.

Из текущей спецификации не следует возвращать v1 runtime, декодеры прежних форматов, compatibility aliases или migration chains ради исторического плана/тестов. Сохраняются требуемые пользовательские возможности, а не старые API и представление данных.

Доказательства текущего состояния: [аудит и повторная проверка](RECTOR_V2_AUDIT_RECHECK_2026-10-03.md).
